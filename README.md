# 📊 Student Performance Analysis Using Pandas

## 📌 Project Overview

This project focuses on analysing student academic performance using Python and the Pandas library.

The program reads student information from a CSV dataset, performs basic data cleaning, and analyses student marks, attendance, study hours, and department-wise performance.

The main purpose of this project is to understand how Pandas can be used for data manipulation, cleaning, and analysis.

## 🎯 Objectives

- Load and read data from CSV files.
- Understand and explore datasets using Pandas.
- Identify missing values and duplicate records.
- Calculate average student marks.
- Identify students with the highest and lowest marks.
- Analyse department-wise performance.
- Categorise students based on their results.
- Export the analysed dataset into a new CSV file.

## 📋 Dataset Description

The project uses a sample student dataset containing the following columns:

| Column | Description |
|---|---|
| Name | Student name |
| Age | Student age |
| Department | Student's department |
| Study_Hours | Daily study hours |
| Attendance | Attendance percentage |

**Note:** The dataset contains sample data created for learning and demonstration purposes.

## 📊 Features

1. **Data Loading:** Reads student records from a CSV file.
2. **Data Exploration:** Displays dataset information and records.
3. **Data Cleaning:** Checks for missing values and duplicate records.
4. **Statistical Analysis:** Calculates average marks and identifies top performers.
5. **Department Analysis:** Calculates average marks for each department.
6. **Result Classification:** Categorises students as Pass or Fail.
7. **Data Export:** Saves the final analysed dataset as `analysed_students.csv`.
